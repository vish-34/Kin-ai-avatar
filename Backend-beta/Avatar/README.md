# 🎭 Kin-ai-avatar | Living Conversational AI Avatar (30+ FPS)

> 💡 **Unified Single-Notebook Recommendation**:
> To run **both Voice (OmniVoice) and Avatar (MuseTalk) simultaneously on one Colab GPU with a single public URL**, use **[`Backend/kin_avatar_unified_colab.ipynb`](../kin_avatar_unified_colab.ipynb)**! You only need to paste one `COLAB_SERVER_URL` into `Backend/.env`.

Real-time, interactive, photorealistic talking avatar system powered by **MuseTalk (v1.5 / v1.0)** with **living video-driven motion (natural breathing, head sway, and eye blinks)**, **one-time avatar preparation caching (0ms pre-processing)**, and **sub-300ms real-time streaming lip-sync** over **Cloudflare / ngrok tunneling**.

---

## ⚡ Key Capabilities

- **Living Video-Driven Motion (HeyGen / Simli Style)**: Upload a 5–10 second video clip of a person recorded on a phone or camera (gently looking at the camera, breathing, smiling, and naturally blinking). The server extracts frames, aligns face boxes, and caches them permanently.
- **Seamless Ping-Pong Looping**: Frames smoothly oscillate forward and backward (`0 ➔ N ➔ 0`) so long speeches and idle waiting states never suffer from abrupt jump cuts or head teleports.
- **Sub-300ms Real-Time Conversational Streaming**: Delivers live video frames chunk-by-chunk at **30+ FPS** over NDJSON streaming for **true 1-on-1 live conversation**.
- **0ms Pre-Processing for Future Speeches**: Any future audio sent for a registered avatar reuses the cached frames and VAE latents immediately with **zero re-detection overhead**.
- **1-Click Public Tunnel (Cloudflare & ngrok)**: Generates a public URL via **Cloudflare Tunnel (100% Free, zero tokens or accounts needed)** or **ngrok**, connecting directly to your local studio CLI or frontend!
- **Direct OmniVoice Integration**: Directly drives the avatar using audio generated by the zero-shot voice cloning pipeline (`Backend/Voice/clone_out.wav`).
- **Free Google Colab T4 GPU**: Runs 100% free on standard Google Colab GPU runtime without package or C++ compilation errors.

## 📱 How to Record a Living Avatar Video Clip

For the best **HeyGen-level photorealism**:
1. Record a **5 to 10-second video** of the person using your phone or webcam.
2. Have the person:
   - Look directly into the camera in clear, even lighting.
   - Gently smile, naturally breathe, and blink normally.
   - Keep their mouth relatively closed/relaxed (idle state).
   - Keep subtle, natural micro-movements (slight head sway or nodding).
3. Save as `.mp4`, `.mov`, or `.webm` and drop it into `Backend/Avatar/`.

*(A ready-to-test sample video `sample_dadaji_idle.mp4` is already provided in `Backend/Avatar/`!)*

## 🚀 Quick Start Guide

### Step 1: Run MuseTalk Server on Google Colab GPU

1. Open [Google Colab](https://colab.research.google.com/).
2. Click **Upload** and upload `Backend/Avatar/MuseTalk_Colab_Fixed.ipynb`.
3. In Colab, go to **Runtime > Change runtime type** and select **T4 GPU**.
4. Run the notebook cells:
   - **Step 1: Automated Setup**: Prepares the isolated Python 3.10 environment with prebuilt MMCV wheels, downloads official MuseTalk v1.5/v1.0 weights, and installs FastAPI + Cloudflare/ngrok (~4 mins).
   - **Step 2: Launch Real-Time Streaming Server & Public Tunnel**:
     - Choose `Cloudflare (Recommended - Free, No Token)` or `ngrok`.
     - Click **Run**.
     - When ready, it displays your public tunnel URL:
       ```
       ========================================================================
       🎉 REAL-TIME LIVING AVATAR SERVER IS ONLINE!
       🔗 Public Tunnel URL: https://random-id.trycloudflare.com
       ========================================================================
       ```
5. Copy the generated public URL.

---

### Step 2: Configure Local Environment

Add your Colab Avatar URL to `Backend/.env`:

```env
COLAB_AVATAR_URL=https://your-tunnel-url.trycloudflare.com
```

*(Note: If left blank, `interactive_avatar.py` will prompt you for the URL on launch and save it automatically into `.env`!)*

---

### Step 3: Run Interactive Avatar Studio

Run the local terminal client from `Backend/Avatar`:

```powershell
python interactive_avatar.py
```

Choose your desired experience mode:
1. **🌟 Live Interactive Conversation**:
   - Opens the avatar window with a living idle loop (breathing, blinking).
   - Type or speak in the terminal.
   - Dadaji speaks back with sub-second streaming lip-sync and audio playback.
   - Seamlessly returns to idle breathing/blinking when done!
2. **📹 Generate Studio MP4 Video**:
   - Generates full studio-grade talking MP4 video with synced AAC audio and auto-launches media player.
3. **⚡ Benchmark Real-Time Stream**:
   - Measures time-to-first-frame (TTFF) and streaming FPS.

## 🌐 API Reference (Colab Server)

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Verifies GPU status, loaded VRAM, and lists cached avatar IDs |
| `POST` | `/register_avatar` | One-time video/photo ingestion: extracts face landmarks, VAE latents, masks, and caches in RAM for 0ms reuse |
| `POST` | `/lipsync_stream` | Sub-300ms real-time NDJSON frame streaming (`{"frame_index": i, "fps": 25, "image_base64": "..."}`) |
| `POST` | `/lipsync_file` | Studio-grade MP4 video with synced AAC audio |
| `GET` | `/idle_frame` | Returns individual idle ping-pong loop frame |
